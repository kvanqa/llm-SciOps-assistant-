# Global Sync Procedure

Global sync must be run every 72 hours to keep all antennas time-aligned.
Navigate to the sync panel in KATGUI and trigger a full array sync. Confirm
all antennas report green status before resuming observations.

# Indexer Position Reset

If an antenna's receiver indexer position is stuck, reset it via the
indexer control panel. Wait for the AP to confirm the new position before
re-enabling the antenna in the observation schedule.

# Handover Notes

At the end of each shift, record the number of available antennas, antennas
in maintenance, and any time-loss events, so the incoming operator has full
context.
